# Week 3: Interactive Greeting App

## About the Project

This is my Week 3 assignment for the Averon Academy 8-Week Developer Program.

The Interactive Greeting App allows visitors to enter their names and receive personalized greetings.

## Features

- Personalized greetings using the visitor's name
- Helpful message when the name field is empty
- Background color-changing button
- Responsive design for mobile devices
- JavaScript interactions without reloading the page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub

## Project Files

- `index.html` - Contains the webpage structure.
- `style.css` - Contains the styling and responsive layout.
- `script.js` - Handles greetings, input validation, and background changes.

## How to Use

1. Open `index.html` in a web browser.
2. Enter your name in the input field.
3. Click the "Say Hello!" button.
4. Read your personalized greeting.
5. Click "Change Background Color" to try different backgrounds.

## What I Learned

Through this project, I practised selecting HTML elements with JavaScript, handling events, reading user input, using conditional statements, and updating webpage content.
