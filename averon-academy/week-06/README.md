# Week 6 – React Task Manager

## Project Description
A simple and responsive Task Manager built with React for the Averon Academy Developer Program.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Save tasks using localStorage.
- Responsive design.

## Technologies
- React
- JavaScript
- HTML
- CSS
- Vite

## Learning Outcomes
- React components
- Props
- useState
- useEffect
- Event handling
- localStorage
- Array methods
