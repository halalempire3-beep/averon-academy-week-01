# Week 4: API-Powered Posts Explorer

## Project Overview

The API-Powered Posts Explorer is a responsive web application built with HTML, CSS, and JavaScript. It fetches posts from an online API and allows users to search for posts by title.

## Features

* Fetches posts from the JSONPlaceholder API.
* Displays a loading message while posts are being fetched.
* Shows each post's title and body.
* Allows users to search posts by title.
* Displays a message when no posts match the search.
* Shows an error message if the posts cannot be loaded.
* Uses a responsive layout for desktop, tablet, and mobile screens.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* JSONPlaceholder API
* GitHub

## API Used

The application gets its data from:

https://jsonplaceholder.typicode.com/posts

## How to Use

1. Open the application in a web browser.
2. Wait for the posts to load.
3. Enter a word in the search field to find posts by title.
4. Clear the search field to display all posts again.
