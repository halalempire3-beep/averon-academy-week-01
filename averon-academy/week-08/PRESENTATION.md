# Student Task Manager Pro

## 1. Introduction
Student Task Manager Pro is a responsive web application designed to help students organize academic tasks, manage deadlines, and track their progress.

## 2. Problem Being Solved
Students sometimes forget assignments, miss deadlines, and struggle to prioritize their academic responsibilities.

This application provides a simple way to organize and monitor tasks.

## 3. Main Features
- Add, edit, and delete tasks.
- Set task due dates.
- Assign High, Medium, or Low priority.
- Mark tasks as completed.
- Search and filter tasks.
- View task statistics on a dashboard.
- Save tasks using browser localStorage.

## 4. Technologies
- React
- JavaScript
- HTML
- CSS
- React Hooks
- localStorage
- Vite

## 5. What I Learned
I practiced building reusable components, managing state, handling user input, using React Hooks, saving data in localStorage, and creating responsive designs.

## 6. Conclusion
This project demonstrates how React can be used to build a practical application that solves an everyday student problem.
